# wxylib/web

Browser app for wxylib, the successor to
[rwarp-wasm](https://github.com/hypertidy/rwarp): warp in the browser
with the same pipeline as the `wxy` command, CRS through proj-wasm.

Not started. Design doc 03 (section 5, "Browser") lists what has to come
first: wasm builds of the I/O crates, codecs that build for wasm, and
CORS for HTTP range reads.

New to wxylib? The [intro page](https://github.com/wxylib/docs#readme)
says what works today. Design and roadmap:
[wxylib/design](https://github.com/wxylib/design).
