A multidimensional VRT, read in the browser

A GDAL multidimensional VRT (mdim.vrt) is a small XML file that stacks many files into one array: dimensions, coordinates, units, scale and offset, and for each slice the file it comes from. This page fetches one, parses it in plain JavaScript, and reads the slice you pick by doing what the VRT says: find the <Source> whose DestSlab covers that index, open its COG with range requests (wxy-tiff in WebAssembly), warp it onto the canvas (wxy-warp), and apply the VRT's nodata, scale and offset. No GDAL, no tile server.
