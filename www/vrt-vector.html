A vector VRT, read in the browser

An OGR VRT is a few lines of XML that make a dataset out of other files: which layers, which fields, points from two columns, geometry from WKT, an SQL filter, a region, a reprojection, a union. This page reads the XML as GDAL does and draws the layers it describes from their sources, over HTTP.

VRT

Edit the XML and open it again. Relative paths in SrcDataSource are read next to the VRT's address; /vsicurl/ and plain URLs need a server that allows CORS (and range requests, for FlatGeobuf).

Notes

    What this page reads, and what it does not
    • OGRVRTLayer: SrcDataSource (with relativeToVRT), SrcLayer, SrcSQL, FID, Style, GeometryType, LayerSRS, Field (name, src, type), SrcRegion, ExtentXMin and the rest (to zoom to).
    • GeometryField encodings Direct, None, PointFromColumns (x, y, z), WKT and WKB (bytes or hex), with reportSrcColumn, SRS and SrcRegion; the first one only.
    • OGRVRTWarpedLayer (SrcSRS, TargetSRS) and OGRVRTUnionLayer (SourceLayerFieldName, FieldStrategy, PreserveSrcFID, LayerSRS, Field), nested as deep as you like.
    • SrcSQL as OGR SQL: SELECT * or fields (with AS), one layer, WHERE (AND, OR, NOT, comparisons, IN, BETWEEN, LIKE, ILIKE, IS NULL, arithmetic), ORDER BY, LIMIT, OFFSET. No functions, joins or SQLite dialect.
    • Sources by file extension: GeoJSON, FlatGeobuf (read through its spatial index, for the view), CSV (values as strings, as GDAL reads them) and GeoParquet (WKB, the first 20,000 rows). Not GeoPackage, shapefiles, databases or a nested VRT.
    • SRS: EPSG codes from a short list (with every UTM zone), WGS84 and OGC:CRS84, PROJ strings and WKT, by proj4js. Coordinates are longitude, latitude, as GDAL's VRT driver orders them.
    • SrcRegion keeps features that meet the region; with clip="true" they are not clipped. OGR style strings colour the map (PEN, BRUSH, SYMBOL colours, widths, dashes).
    • Anything else in the XML is listed under Notes. The examples are checked against GDAL 3.12, feature by feature (scripts/vrt-test.mjs).
