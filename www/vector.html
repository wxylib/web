GeoParquet, queried in the browser

SQL over remote GeoParquet with DuckDB (wasm): only the file footers and the row groups the query needs are fetched, with range requests. The result is a table, and its geometry column is drawn on the map.

Source

Query

{files} is the source's file list; {xmin}, {ymin}, {xmax}, {ymax} are the map view in longitude and latitude. The column named geometry (WKB) is drawn. Dashed boxes are the source's files, where their extents are known: the data is inside them.
