BRAN2023 ocean temperature, read through its byte table

Every pixel here comes from a monthly netCDF file of about 5 GB on NCI's THREDDS server. The page holds a table of where each 300 x 300 chunk sits in those files (path, offset, size) and fetches only the chunks it draws, with one HTTP range request each, then inflates and unshuffles them in the browser. No netCDF or HDF5 library, no tile server, no copy of the data.
